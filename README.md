# Mohammad Sajjad Dini Portfolio

Personal portfolio and landing page for Mohammad Sajjad Dini, focused on digital transformation, product leadership, e-business, CRM, and customer experience.

## GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder.

The site is fully static and requires no build step.

## Included files

- `index.html` - responsive portfolio website
- `assets/headshot.png` - profile portrait
- `assets/Mohammad-Sajjad-Dini-Resume.pdf` - downloadable resume
